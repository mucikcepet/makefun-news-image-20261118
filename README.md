18 Nov 2026 world news in one image: APEC opens in Shenzhen, Xi meets Putin and Trump joins them Thursday, the Quad meets in Manila, US jets hit a missile site on Qeshm Island and drones are intercepted over Bahrain and Kuwait, Ukraine hits the Kerch Bridge a second day, Democrats take the US Senate 56-44, Nvidia's board rejects Huang's return, Cyclone Akvan nears India, the US loses its measles-free status and Ebola passes 11,000 cases in DR Congo.

A Node 22 program that draws the whole 1024x1024 image procedurally — a 5x7 bitmap font and a hand-written PNG encoder, standard library only, no network, deterministic: two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (19 KB, 1024x1024). In the grader it writes `/output/entry.png`.
